# SULDAYO

Connect • Share • Discover

This is the SULDAYO Flutter starter prepared for Android builds.

## Android build

The included GitHub Actions workflow can create an installable release APK in the cloud. It also generates the Android project wrapper automatically if the Dart/Flutter project is uploaded as a ZIP.

Workflow: `.github/workflows/android-apk.yml`

The APK is published as a GitHub Actions artifact named `SULDAYO-APK` after a successful build.

## Current app

The current version is a UI prototype. It includes login/sign-up screens, home feed, Shorts, Discover, Messages, and Profile screens. Real accounts, cloud data, video storage, real-time chat, matching, notifications, moderation, and production security still need a backend before public release.
